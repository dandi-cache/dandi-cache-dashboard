# DANDI Cache (Dashboard)

A quick reference for the current state of every [DANDI cache](https://github.com/dandi-cache).

Download the table, tab-separated with sizes in bytes, from GitHub's CDN:

```bash
curl -O https://raw.githubusercontent.com/dandi-cache/dandi-cache-dashboard/dashboard/dashboard.tsv
```
